1//! Bayesian rate-estimator engine: per-peer scalar Kalman filters plus
2//! uncertainty-aware admission.
3//!
4//! # Model
5//!
6//! Each peer's true accepted rate is a latent variable observed through
7//! delayed, noisy gossip samples. Per (peer, scope) we run a scalar Kalman
8//! filter with random-walk dynamics:
9//!
10//! ```text
11//! state:        x_k = x_{k-1} + w_k,   w_k ~ N(0, q · Δt)
12//! observation:  z_k = x_k + v_k,       v_k ~ N(0, r)
13//! ```
14//!
15//! where `q` (process noise, rps²/s) encodes how fast peer rates are
16//! believed to change and `r` (measurement noise, rps²) the sampling error
17//! of the peer's sliding-window rate estimate. The filter equations are the
18//! standard scalar predict/update cycle (Welch & Bishop, "An Introduction to
19//! the Kalman Filter", UNC-Chapel Hill TR 95-041, eqs. 1.9–1.12):
20//!
21//! ```text
22//! predict:  x̂⁻ = x̂           (random walk: F = 1, no control input)
23//!           P⁻ = P + q · Δt
24//! update:   K  = P⁻ / (P⁻ + r)
25//!           x̂  = x̂⁻ + K (z − x̂⁻)
26//!           P  = (1 − K) P⁻
27//! ```
28//!
29//! Between gossip samples no update runs, but the *usable* variance of a
30//! peer's estimate at query time is `P + q · age`: *staleness is
31//! uncertainty*. This subsumes Milestone 3's linear staleness decay with a
32//! principled equivalent — an old observation doesn't fade toward zero rate,
33//! it stays at its last mean with ever-wider error bars.
34//!
35//! # Admission policy
36//!
37//! The cluster estimate is the sum of independent per-peer Gaussians:
38//!
39//! ```text
40//! Ŝ = Σ x̂ᵢ          (peer total mean)
41//! V = Σ (Pᵢ + q·ageᵢ)  (peer total variance; independence assumed)
42//! ```
43//!
44//! The node then admits against the estimate's upper confidence bound,
45//! taking whatever headroom the cluster target leaves:
46//!
47//! ```text
48//! refill = cluster_target − (Ŝ + z·√V)
49//! ```
50//!
51//! clamped to `[min_rate/n, max_rate/n]` (n = 1 + live peers). With
52//! symmetric saturated demand this fixed-points at the fair share
53//! `(cluster_target − (n−1)·z·σ)/n`; under skew, cold nodes' low observed
54//! rates leave headroom the hot node claims automatically — share division
55//! is demand-weighted without explicit coordination. The `z·√V` term makes
56//! the node conservative exactly when information is stale (partition,
57//! churn) and aggressive when the estimate is tight.
58//!
59//! # Membership
60//!
61//! Peers whose observations exceed `stale_timeout` are dropped from the
62//! filter bank entirely. The random-walk model keeps a silent peer's *mean*
63//! at its last value forever (only the variance grows), so without a
64//! membership cutoff a dead peer would permanently reserve headroom. The
65//! cutoff is a transport/membership concern, deliberately identical to the
66//! gossip layer's liveness horizon; estimation handles everything short
67//! of it.

76/// Tuning parameters for [`BayesianEngine`] (and the estimator half of
77/// [`super::HybridEngine`]).
78///
79/// Defaults are simulator-derived (Milestone 5.3 sweep, seed 42, recorded
80/// in `docs/engine-comparison.md`). For the pure Bayesian engine the
81/// estimate-and-set feedback race must be damped by a slow Kalman gain:
82/// `q = 1, r = 100` was the only swept corner where most scenarios
83/// converge (fast-gain settings oscillate at ±150 rps). `r = 100` is also
84/// what Poisson counting noise predicts for a 1 s window at the
85/// benchmark's ~100 rps per-node shares (variance ≈ λ). `z = 1` is the
86/// roadmap's documented starting point; the sweep showed z mainly trades
87/// undershoot for convergence speed with no clearly better setting.
88///
89/// The hybrid engine wants the opposite: a fast filter (its PID supplies
90/// the damping) — use [`BayesianParams::hybrid_default`] there.
91#[derive(Debug, Clone, Copy)]
92pub struct BayesianParams {
93    /// Process noise `q` (rps²/s): how fast peer rates are believed to
94    /// change. Larger values track fast-moving peers more closely but keep
95    /// wider error bars on stale data.
96    pub process_noise: f64,
97
98    /// Measurement noise `r` (rps²): variance of a single gossiped rate
99    /// sample. For a 1 s sliding-window estimate of a Poisson stream at
100    /// rate λ, the counting error alone gives variance ≈ λ, so values well
101    /// below the per-node share underweight real sampling noise.
102    pub measurement_noise: f64,
103
104    /// Confidence multiplier `z` for the admission bound
105    /// (`mean + z·σ`). 0 admits against the raw mean; 1 (default) against
106    /// one standard deviation of headroom pessimism.
107    pub confidence_z: f64,
108
109    /// Membership horizon: peers silent longer than this are dropped from
110    /// the filter bank. Should match the transport's stale timeout.
111    pub stale_timeout: Duration,
112}
113
114impl Default for BayesianParams {
115    fn default() -> Self {
116        BayesianParams {
117            process_noise: 1.0,
118            measurement_noise: 100.0,
119            confidence_z: 1.0,
120            stale_timeout: DEFAULT_STALE_TIMEOUT,
121        }
122    }
123}

138        }
139    }

142/// One peer's scalar Kalman filter state.
143#[derive(Debug, Clone)]
144struct PeerFilter<T> {
145    /// Posterior mean x̂ at the last incorporated sample
146    mean: T,
147
148    /// Posterior variance P at the last incorporated sample
149    variance: T,
150
151    /// Engine-clock time of the last incorporated sample (t_now − age);
152    /// used both to detect new samples and to size the predict step
153    last_sample_time: T,
154}
155
156/// Shared per-peer Kalman filter bank (used by both the Bayesian and hybrid
157/// engines). Keyed by peer id in a `BTreeMap` so summation order — and
158/// therefore floating-point results — is deterministic.
159#[derive(Debug, Clone)]
160pub(crate) struct FilterBank<T> {
161    filters: BTreeMap<String, PeerFilter<T>>,
162
163    /// Engine-local clock, advanced by `input.dt` each update. Only
164    /// differences of this clock are ever used.
165    clock: T,
166
167    process_noise: T,
168    measurement_noise: T,
169    stale_timeout: Duration,
170}
171
172/// A peer's estimate evaluated at the current engine clock.
173#[derive(Debug, Clone, Copy)]
174pub(crate) struct PeerEstimate<T> {
175    pub mean: T,
176    pub variance: T,
177}
178
179impl<T: Float + FromPrimitive + Copy> FilterBank<T> {
180    pub(crate) fn new(params: &BayesianParams) -> Self {
181        FilterBank {
182            filters: BTreeMap::new(),
183            clock: T::zero(),
184            process_noise: T::from_f64(params.process_noise).unwrap(),
185            measurement_noise: T::from_f64(params.measurement_noise).unwrap(),
186            stale_timeout: params.stale_timeout,
187        }
188    }
189
190    /// Advance the clock, incorporate new samples, prune dead peers, and
191    /// return each live peer's estimate at the current time.
192    pub(crate) fn observe(
193        &mut self,
194        peers: &[super::PeerRate<T>],
195        dt: Duration,
196    ) -> Vec<PeerEstimate<T>> {
197        self.clock = self.clock + T::from_f64(dt.as_secs_f64()).unwrap();
198
199        let mut estimates = Vec::with_capacity(peers.len());
200        let mut seen: Vec<&str> = Vec::with_capacity(peers.len());
201
202        for obs in peers {
203            // Past the membership horizon the peer is presumed gone; skip it
204            // here and prune its filter below
205            if obs.age >= self.stale_timeout {
206                continue;
207            }
208            seen.push(obs.id.as_str());
209
210            let age = T::from_f64(obs.age.as_secs_f64()).unwrap();
211            let sample_time = self.clock - age;
212
213            let filter = self
214                .filters
215                .entry(obs.id.clone())
216                .or_insert_with(|| PeerFilter {
217                    // First contact: the sample itself is the prior, with a
218                    // single measurement's worth of variance (Welch & Bishop
219                    // §4: filter initialization from the first observation)
220                    mean: obs.rate,
221                    variance: self.measurement_noise,
222                    last_sample_time: sample_time,
223                });
224
225            // A strictly newer sample time means the transport delivered a
226            // fresh observation (ages reset on receipt); run one
227            // predict/update cycle sized by the inter-sample gap
228            let gap = sample_time - filter.last_sample_time;
229            if gap > T::zero() {
230                let predicted_var = filter.variance + self.process_noise * gap;
231                let gain = predicted_var / (predicted_var + self.measurement_noise);
232                filter.mean = filter.mean + gain * (obs.rate - filter.mean);
233                filter.variance = (T::one() - gain) * predicted_var;
234                filter.last_sample_time = sample_time;
235            }
236
237            // Estimate at the current clock: mean is unchanged under the
238            // random walk; variance grows with time since the last sample
239            let since_sample = self.clock - filter.last_sample_time;
240            estimates.push(PeerEstimate {
241                mean: filter.mean,
242                variance: filter.variance + self.process_noise * since_sample,
243            });
244        }
245
246        // Prune peers no longer observed (or past the horizon) so a dead
247        // peer's mean cannot reserve headroom forever
248        self.filters.retain(|id, _| seen.contains(&id.as_str()));
249
250        estimates
251    }
252}

254/// Pure Bayesian estimate-and-set engine. See the module docs for the
255/// model, admission policy, and parameter meanings.
256#[derive(Debug, Clone)]
257pub struct BayesianEngine<T> {
258    bank: FilterBank<T>,
259    confidence_z: T,
260    last_setpoint: Option<T>,
261}
262
263impl<T: Float + FromPrimitive + Copy> BayesianEngine<T> {
264    pub fn new(params: BayesianParams) -> Self {
265        BayesianEngine {
266            bank: FilterBank::new(&params),
267            confidence_z: T::from_f64(params.confidence_z).unwrap(),
268            last_setpoint: None,
269        }
270    }
271}
272
273impl<T: Float + Signed + FromPrimitive + Copy + Send + Sync + std::fmt::Debug> RateController<T>
274    for BayesianEngine<T>
275{
276    fn update(&mut self, input: &ControlInput<'_, T>) -> T {
277        let Some(cluster_target) = input.cluster_target else {
278            // Single-node mode: estimation adds nothing (there are no peers
279            // to estimate); the token bucket enforces the static target
280            let refill = num_traits::clamp(input.target_rate, input.min_rate, input.max_rate);
281            self.last_setpoint = Some(refill);
282            return refill;
283        };
284
285        let estimates = self.bank.observe(input.peers, input.dt);
286        let live = estimates.len();
287
288        let mut peer_sum = T::zero();
289        let mut peer_var = T::zero();
290        for e in &estimates {
291            peer_sum = peer_sum + e.mean;
292            peer_var = peer_var + e.variance;
293        }
294
295        // Admit against the upper confidence bound of the peer total
296        let ucb = peer_sum + self.confidence_z * peer_var.sqrt();
297        let headroom = cluster_target - ucb;
298
299        let n = T::from_usize(1 + live).unwrap();
300        let refill = num_traits::clamp(headroom, input.min_rate / n, input.max_rate / n);
301        self.last_setpoint = Some(refill);
302        refill
303    }
304
305    fn setpoint(&self) -> T {
306        // The engine's effective local target is the admission rate itself
307        self.last_setpoint.unwrap_or_else(T::zero)
308    }
309}

316    fn peer(id: &str, rate: f64, age_ms: u64) -> PeerRate<f64> {
317        PeerRate {

319            rate,
320            age: Duration::from_millis(age_ms),
321        }

324    fn input<'a>(
325        local_rate: f64,
326        peers: &'a [PeerRate<f64>],
327        cluster_target: Option<f64>,
328    ) -> ControlInput<'a, f64> {
329        ControlInput {
330            local_rate,
331            peers,
332            target_rate: 100.0,
333            cluster_target,
334            min_rate: 30.0,
335            max_rate: 600.0,
336            dt: Duration::from_secs(1),

340    #[test]
341    fn test_no_peers_takes_full_target() {
342        let mut engine = BayesianEngine::new(BayesianParams::default());
343        let refill = engine.update(&input(0.0, &[], Some(300.0)));
344        assert_eq!(refill, 300.0, "cold start: no peers → full cluster target");
345    }

347    #[test]
348    fn test_headroom_shrinks_with_peer_load() {
349        let mut engine = BayesianEngine::new(BayesianParams::default());
350        let peers = vec![peer("a", 100.0, 0), peer("b", 100.0, 0)];
351        let refill = engine.update(&input(100.0, &peers, Some(300.0)));
352        // Headroom = 300 − (200 + z·σ) < 100, and above min bound 30/3
353        assert!(refill < 100.0, "got {}", refill);
354        assert!(refill > 10.0, "got {}", refill);
355    }

357    #[test]
358    fn test_staleness_widens_error_bars() {
359        let params = BayesianParams::default();
360        let mut fresh_engine = BayesianEngine::new(params);
361        let mut stale_engine = BayesianEngine::new(params);
362
363        // Both engines see the same peer, then it goes silent for one
364        let warm = vec![peer("a", 100.0, 0)];
365        fresh_engine.update(&input(100.0, &warm, Some(300.0)));
366        stale_engine.update(&input(100.0, &warm, Some(300.0)));
367
368        let fresh = fresh_engine.update(&input(100.0, &[peer("a", 100.0, 100)], Some(300.0)));
369        let stale = stale_engine.update(&input(100.0, &[peer("a", 100.0, 8000)], Some(300.0)));
370        assert!(
371            stale < fresh,
372            "stale info must admit less: stale {} vs fresh {}",
373            stale,
374            fresh
375        );
376    }

378    #[test]
379    fn test_dead_peer_dropped_frees_headroom() {
380        let mut engine = BayesianEngine::new(BayesianParams::default());
381        let warm = vec![peer("a", 200.0, 0)];
382        let before = engine.update(&input(50.0, &warm, Some(300.0)));
383
384        // Peer past the membership horizon: filter pruned, headroom back
385        let gone = vec![peer("a", 200.0, 15_000)];
386        let after = engine.update(&input(50.0, &gone, Some(300.0)));
387        assert!(before < 150.0);
388        assert_eq!(after, 300.0, "dead peer must not reserve headroom");
389    }

391    #[test]
392    fn test_filter_converges_to_true_rate() {
393        let params = BayesianParams {
394            process_noise: 1.0,
395            measurement_noise: 100.0,
396            ..BayesianParams::default()
397        };
398        let mut bank = FilterBank::<f64>::new(&params);
399        // Repeated samples at 100 rps, arriving fresh every second
400        let mut mean = 0.0;
401        for _ in 0..30 {
402            let est = bank.observe(&[peer("a", 100.0, 0)], Duration::from_secs(1));
403            mean = est[0].mean;
404        }
405        assert!((mean - 100.0).abs() < 1.0, "converged to {}", mean);
406    }

408    #[test]
409    fn test_deterministic_summation_order() {
410        // BTreeMap keying: identical inputs in different list order give
411        // identical results
412        let mk = || BayesianEngine::new(BayesianParams::default());
413        let (mut e1, mut e2) = (mk(), mk());
414        let fwd = vec![peer("a", 10.0, 0), peer("b", 20.0, 0), peer("c", 30.0, 0)];
415        let rev: Vec<_> = fwd.iter().rev().cloned().collect();
416        let r1 = e1.update(&input(5.0, &fwd, Some(300.0)));
417        let r2 = e2.update(&input(5.0, &rev, Some(300.0)));
418        assert_eq!(r1, r2);
419    }
